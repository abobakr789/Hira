# أدوات توليد عروض الدراسات الاجتماعية

أُعيد بناؤها من العروض المنشورة نفسها بعد فقدان النسخة الأصلية.
مثبتة: 69/69 عرضًا تُستخرج وتُعاد كتابتها بنفس البايتات تمامًا.

- `deck.py` — تقسيم الشرائح وعُقد النص (يتجاهل نصوص الـ SVG، ويجمع تتابع `span.tw`).
- `slots.py` — جدول الخانات المسمّاة (364 خانة موزّعة على 30 شريحة).
- `fit.json` — منحنيات حجم الخط التلقائي المستخرجة من العروض (دقة 99.9% ±1px).
- `gen.py` — `extract(html)` لقراءة درس، و`render(template, fields, scenes, art)` لتوليد درس.
- `qa.py` — فحص آلي: 30 شريحة، تجاوز النص، الصور المكسورة، أخطاء JavaScript.
