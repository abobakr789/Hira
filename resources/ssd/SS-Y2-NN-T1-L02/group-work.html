📋 Group 1: Class rules

Group members:
Task: Write three class rules about respect.

Steps

1Think of three rules about respect.

2Write each rule on a card.

3Draw a picture for each rule.

4Read your rules to the class.

Roles

LeaderSpeakerWriter / DrawerTimekeeper
 
 
🚀 Challenge: add a picture for each rule.
