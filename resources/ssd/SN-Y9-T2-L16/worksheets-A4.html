1أختار الإجابة الصحيحة:
1. من سنع المرأة في استقبال الضيوف:
( أ ) الاعتذار عن الاستقبال( ب ) صنع القهوة وإعداد الفوالة( ج ) إغلاق الباب
2. الضيوف الذين ترحب بهم المرأة:
( أ ) الأقارب فقط( ب ) الغرباء فقط( ج ) الجيران والأقارب والأصدقاء والغرباء
3. تتولى المرأة الاستقبال حين:
( أ ) يغيب الزوج( ب ) يحضر الزوج فقط( ج ) لا يوجد ضيوف
2أضع ( ✓ ) أو ( ✗ ) وأصوّب الخطأ:
كانت المرأة في صدارة المرحبين بالضيوف. (    )
عرف المجتمع الإماراتي أبوابًا مغلقة أمام الضيوف. (    )
من سنعها صنع القهوة وإعداد الفوالة. (    )
تقدم المرأة العود والعطور للزائرين. (    )

إيضاح تعليمي: الاستقبال مع بالغ موثوق، وليس تكليفا للطفل باستقبال الغرباء وحده؛ التدريب بأدوات باردة فارغة.
